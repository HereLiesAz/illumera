# Lessons

- The central Play release runs `:app:testDebugUnitTest`; a green PR check is not a green release. After a merge, read the `central-run-failure` issue and the failed job's log in HereLiesAz/workflows before assuming the build is fine.
- Screens and scaffolds that Compose unit tests render directly (`DetailsScreen`, `BasePlayerScaffold`) must not call `hiltViewModel()` for new data: the tests have no Hilt and fail with `IllegalStateException`. Pass new state and callbacks as defaulted parameters from `MainActivity` instead.
- The Android SDK can be installed here (ANDROID_HOME=/home/user/android-sdk), so compile and run `./gradlew :app:testDebugUnitTest` before pushing; do not leave the first compile to CI.
- AGP rejects `Provider` in `sourceSets.assets.srcDir`; pass a `File` and make `merge*Assets` depend on the generating task.
- The central release builds run `:app:lintRelease` (and `:app:assembleRelease`, which runs lint-vital), not just unit tests. Gradle 9 fails them if a task reads another task's output without a declared dependency. Generated assets must be registered per variant with `androidComponents.onVariants { variant.sources.assets?.addGeneratedSourceDirectory(task, ...) }`, never `sourceSets.srcDir` plus `dependsOn`. Before pushing build-script changes, run `:app:lintRelease` and `:app:generateReleaseLintVitalReportModel` locally (bundle tasks need signing keys and can't run here).
- Never put per-key-press state (focus, scroll) in the `StateFlow` that Compose derives rows from: each D-pad move then emitted a new `HomeState` and `HomeScreen` re-filtered and re-sorted every row on the main thread. Keep it in its own flow, derive display rows in the ViewModel (`HomeDisplayDeriver`) and key effects on ids/art, not on whole row lists.
- A browse-row card must not set up per-card machinery (`hiltViewModel()`, `Regex(...)`, `LaunchedEffect`, `SubcomposeAsyncImage`, `graphicsLayer { clip = false }`, nested `clip`). The TV `Surface` already clips to its shape; compose a card's long-press menu only once opened (`LazyMediaCardActionMenu`) and keep it composed afterwards so the soundtrack dialog it owns survives.
